# aadd-26
Repositorio para la asignatura de Aplicaciones Distribuidas

Proyectos

- `ejemplos-xml-json`: incluye ejemplos presentados en clase sobre XML, DOM, SAX, JAXB, XPath y distintas APIs para JSON.
- `encuestas`: proyecto que ilustra la aplicación de los patrones Servicio, Repositorio y Especificación, además contenidos de los bloques de persistencia y presentación.
- `ejemplos-persistencia-presentacion`: incluye ejemplos presentados en clase en los bloques de persistencia y presentación.
